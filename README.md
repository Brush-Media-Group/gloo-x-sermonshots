## Gloo Hackathon 2025 Entry

This project is our official entry for the [Gloo AI Hackathon 2025](https://gloo.com/ai/hackathon-2025). The hackathon brings together teams to build innovative faith-based solutions using AI and modern web technologies.

## Project Overview

This repository is organized into two main directories:

- **api/** — Contains all backend services, including data processing, transcript analysis, AI integrations, and API endpoints. Built with NestJS and TypeScript.
- **app/** — Contains all frontend code, including the Svelte-based user interface, components, and client-side logic for interacting with the backend.

## About the App

The app enables users to search for sermon videos and chapters, ask faith-related questions, and discover relevant content powered by AI. It features smart search, chapter navigation, instant results, and related answers from other churches.
